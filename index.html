Help

Click a pose on the left to append it, or drag it onto the page to insert it there. Select shapes on the page to edit them.

Select
Click a shapeselect it
Drag a box on empty pageselect every shape it touches (Shift / Ctrl adds)
Shift+clickselect a range from the last clicked shape
Ctrl+clickadd or remove one shape
Ctrl+A / Escselect all / deselect
Arrange
Drag a shapereorder it; drop it on the bin or off the page to remove it
← → ↑ ↓move the selected shape in the order
Deleteremove the selected shapes
Enterstart a new row after the shape (that row is centred)
Spacing
+ / −widen / narrow the space to the right of the selection, by the same amount for each (narrowing stops where outlines would touch)
Text
1 / 2write a note above / below the selected shape (Ctrl+Enter saves, Esc cancels)
Print options › Pose namesprint each pose's name above or below its shape, in the language you choose
Page
Paper, orientation, Scaleeverything on the page (shapes, lines, text, gaps) scales together; Auto picks the largest readable scale for the fewest pages. Hold Shift while dragging the slider for fine control
Anywhere
Ctrl+Z / Ctrl+Yundo / redo
Type a lettergoes straight into the pose filter (Enter adds the first match, Esc clears)
