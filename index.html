Click a shape to select it: arrow keys move it, Delete removes it, 1 / 2 add text above / below it, + / − widen / narrow the space to its right (narrowing stops where the outlines touch), Enter starts a new row after it (that row is centred), Esc deselects. Drag a box on empty page to select the shapes it touches (Shift/Ctrl adds). Shift+click selects a range, Ctrl+click adds one, Ctrl+A selects all: spacing, line break and Delete then apply to every selected shape, by the same amount. Drag a shape to reorder it, or drop it on the bin or off the page to remove it. Drag a library tile onto the page to insert it there. Paper, orientation and scale (shapes, lines, text and gaps) are set above the toolbar; a smaller scale fits more rows and shapes on a page.
Your program is kept in this browser automatically. Use Export SVG to save it as a file.
